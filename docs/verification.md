# 2.0 驗證報告

2026-11-23，Asia/Taipei。交付版本為 `v1.0.0`。驗證使用獨立 PostgreSQL 16、虛構資料、Chromium 與本機 Mailpit。驗收基準見 [需求說明書 2.0](../Course_Registration_SRS.md)。

| 檢查 | 結果 |
|---|---|
| 後端 PostgreSQL 整合與併發 | **120 通過**。涵蓋選課與分發、推薦與批次確認、資料庫權限、助理診斷、課表查詢及手動寄送。 |
| React / TypeScript | 正式建置通過，Vite 6.4.1。 |
| Chromium 端到端 | **9 通過**。涵蓋兩階段推薦確認、回應遺失重送、區網登入相容性、單學期入口、取消後更新課表、課表寄送及行動版。 |
| 區網 HTTP 回歸 | Chromium 開啟非 localhost 的 HTTP 網址，確認 `randomUUID` 不可用時登入仍回 200。390 像素寬的推薦頁顯示三門可勾選班別，無水平溢出。 |
| 部署流程 | **8 項腳本測試通過**，Bash 語法及 `.env.example` 的 Compose 解析通過。 |
| Migration 與密碼 | 驗證全新資料庫、既有 `0001` 升級、`--sql` 匯出後實際套用至全新資料庫，以及三個用途的 PostgreSQL 帳號使用含 `@`、`/`、`%` 的密碼。兩次 seed 保有相同識別碼。 |
| Mailpit | 待分發的多個上課時段完整送達。正式課表信模擬 TCP 拒絕後，第二次嘗試成功並更新 `SENT`。[SMTP 記錄](mailpit-verification.json) |
| 公開查課效能 | 1,000 班、20 並行、25 次暖機、200 次量測。p50 201.34 ms、p95 **275.20 ms**，達 ≤ 500 ms 目標。[環境與數據](performance.json) · [兩筆 SQL 與 EXPLAIN](explain.txt) |
